# Listen delivery contract

Owner-operated releases use the reviewed root helpers in
[`listener-account-production`](../listener-account-production/README.md) and
[`listener-identity-staging`](../listener-identity-staging/README.md), from a
root-owned clean checkout of the exact qualified `early-birds` commit.

[`v1/README.md`](v1/README.md) describes the separate, inactive runner automation
contract. Its absent helper, units or protected environments are an automation
gap, not evidence that this existing owner-operated path is unavailable. Do not
grant a runner direct access to the owner helpers or infer that automation is
active from this documentation.

Historical launch handoffs and Telegram prose are retained as history only.
They are not current artifact, alert-recipient, Authority-contract, delivery,
or recovery evidence under this contract.
